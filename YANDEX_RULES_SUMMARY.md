# Требования Яндекс Игр — структурированная выжимка

> Источник: `Требования к игре _ Руководство разработчика.pdf` (Яндекс Игры, консоль разработчика).
> Модерация обычно занимает несколько рабочих дней. Отсутствие замечания на устройстве
> разработчика не освобождает от требования — проверка идёт на приближенных к пользователю окружениях.
> Упразднённые пункты оригинальной нумерации в выжимку не включены.

## Легенда статусов (для проекта Kotolyot)

- ✅ — выполнено
- ⚠️ — частично / нужно проверить при заполнении черновика
- ❌ — не реализовано, требуется работа
- ➖ — неприменимо (платформа/фича не используется в этом проекте)

## 4. Требования к рекламе

**Статус проекта: реклама пока не подключена (по решению — будет позже). Все пункты ниже становятся активными в момент интеграции РСЯ.**

| # | Требование | Что нужно сделать при подключении |
|---|---|---|
| 4.1 | Реклама только через SDK Яндекс Игр, без сторонней | Использовать `ysdk.adv.*`, никаких сторонних баннеров |
| 4.2 | Внутренний прогресс сохраняется после перехода по рекламе и возврата | Текущая архитектура (`pauseFromVisibility`/`resumeFromPause`) готова к этому — прогресс и так не сбрасывается при паузе |
| 4.3 | Рекламные блоки — той же ориентации, что игра | Игра портретная — использовать портретные форматы |
| 4.4 | Реклама не мешает взаимодействию, показывается только в логических паузах | Логичные точки: между забегами (после `endGame()`, перед возвратом на старт) |
| 4.5 | При `interstitial`/`rewarded video` звук и геймплей ставятся на паузу | **Важно**: дёргать `pauseFromVisibility()`-подобную логику из `onOpen`/`onClose` callback'ов рекламного API — API рекламы не всегда генерирует `visibilitychange`/`blur` |
| 4.6 | RV — по желанию игрока (кнопка), с понятным текстом о вознаграждении | Если добавите RV — нужна выделенная кнопка с явным описанием награды |
| 4.6.2 | Награда за RV — доп. бонус, не влияющий на возможность продолжить игру | Не делать progression-gate через RV |
| 4.7 | Доп. блоки — только стики-баннеры; кастомные RTB запрещены | — |

## Сводка по критичным пунктам для Kotolyot

### ❌ Требует обязательной доработки перед публикацией
1. **Полноэкранный режим на мобильных устройствах** (п. 1.5.1.1) — не реализован в коде, нужно добавить вызов Fullscreen API.
2. **Монетизация РСЯ** (п. 1.12) — реклама пока сознательно не подключена, добавить перед публикацией.
3. **Обязательные поля заявки в Консоли** (п. 5.3) — заполняются отдельно от кода.

### ⚠️ Нужно проверить/протестировать перед публикацией
- Кросс-браузерное и кросс-платформенное тестирование (Safari, Firefox, реальные Android/iOS устройства).
- Права на все графические ассеты (арты кота, фон, когтеточки).
- Уникальность названия "Котолёт"/"Cat Flight" в каталоге.

### ➖ Осознанно неприменимо (по решению из этого разговора)
- Платформа Android TV — не заявляется.
- Внутриигровые покупки — отсутствуют.
- Облачные сохранения — не используются, только `localStorage`.
- Реклама — временно не подключается (будет отдельной задачей).
- Авторизация через Яндекс ID — не используется, гостевой доступ по умолчанию.

### ✅ Уже полностью соответствует требованиям
